# Data-Driven Development of an ADC Downstream Purification Process

A computational bioprocess-development case study exploring how experimental
process data can be used to optimize post-conjugation purification of an
antibody-drug conjugate (ADC).

The project combines protein purification and downstream-process concepts with
Python-based data analysis to investigate trade-offs between product recovery,
purity, aggregation, residual free drug-linker, and ADC product quality.

> **Project status:** Work in progress. This project is being developed
> incrementally as part of ongoing training in Python and data analytics.

## Project concept

Following antibody-drug conjugation, downstream processing must remove
process-related impurities while maintaining product recovery and critical
quality attributes.

This project models a hypothetical post-conjugation ADC purification
development campaign and asks:

> **Which process conditions provide the best balance between ADC recovery and
> product quality?**

The dataset used in this project will be simulated and clearly identified as
such. It is intended to represent a realistic process-development scenario,
not experimental results generated in the laboratory.
